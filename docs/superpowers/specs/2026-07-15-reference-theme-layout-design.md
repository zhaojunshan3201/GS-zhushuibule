# 参考系统主题与布局改造设计

## 目标

将现有高升注水管理系统的视觉主题和页面布局统一调整为参考系统 `C:\Users\31541\Desktop\bgua\fuzhi222\222` 的风格，同时保持所有现有功能、页面、数据字段、接口、导入导出和交互行为不变。

## 采用方案

采用“统一应用壳层”方案：替换整体视觉框架并让所有现有功能页面在新框架中渲染；不采用逐页重写业务内容的高风险方案。

## 视觉与布局

- 新增首次进入的欢迎页，使用参考系统的深蓝渐变背景、系统介绍、功能概览和进入按钮；它仅控制展示状态，不改变登录、路由或数据加载逻辑。
- 桌面端采用固定 240px 深蓝渐变左侧导航栏；导航保留当前全部菜单项、分组、选中状态与点击行为。
- 内容区采用 60px 白色顶部状态栏，显示当前位置、运行状态和现有用户入口；下方保留页面标题与说明。
- 页面主体使用浅灰背景、白色圆角卡片、细边框、轻阴影、蓝色主色与橙色强调色。
- 指标、图表、筛选工具栏、表格和弹窗仅替换容器、颜色、间距与排版层级；原有字段、操作按钮、排序、筛选、分页、导入导出和编辑流程不变。
- 宽表维持横向滚动和现有列宽策略；小屏时侧栏切换为可收起导航，内容不丢失。

## 实现边界

- 主要修改 `src/App.tsx` 的应用外层结构和 `src/index.css` 的主题组件样式。
- 业务组件、服务端接口、Prisma 模型、共享数据和导入导出逻辑不修改，除非为保持新布局下现有交互可用而必须调整其展示类名。
- 不复制参考系统的业务文案、数据或功能模块；本系统继续使用自己的名称、菜单和业务内容。

## 验收标准

1. 首次进入可见欢迎页，点击后进入系统；刷新后按既定展示策略工作。
2. 每个现有菜单页面都在统一的侧栏、顶部状态栏和卡片内容区中正常打开。
3. 现有功能操作与改造前一致：表格筛选、编辑、保存、导入、导出、图表和弹窗均可用。
4. `npm run lint`、`npm test` 与 `npm run build` 通过。
5. 在桌面宽度和窄屏宽度下检查导航、工具栏、表格横向滚动和主要弹窗，确认没有内容遮挡或无法操作。
