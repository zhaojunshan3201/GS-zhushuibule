## 目标

将当前项目的前端主框架从“左侧边栏后台”切换为参考项目的“顶部横向导航为主”的展示方式，并先完成壳层级别的一致化，包括：

- 全局布局骨架
- 顶部导航
- 全局配色与视觉变量
- 通用卡片、表格、筛选条、按钮、页脚
- 登录页、欢迎页、首页外层风格

本轮不追求逐页 1:1 重写业务内容，而是优先让整个系统在第一视觉、导航方式、内容画布和通用组件层面与参考项目保持一致。

## 范围

### 本轮包含

- 用顶部横向导航替代当前主导航框架
- 统一页面背景、主内容区宽度、区块间距、页脚风格
- 统一颜色体系为参考项目的红白灰主视觉和浅蓝表头体系
- 统一通用表格、筛选器、按钮、卡片容器样式
- 调整登录页、欢迎页和首页外层，使其首先呈现参考项目气质
- 保留现有页面切换逻辑、权限控制、数据请求和后端接口

### 本轮不包含

- Oracle / PostgreSQL 数据流改造
- 后端接口结构调整
- 逐页深度重写所有业务页面
- 大规模拆分 `src/App.tsx`
- 图表数据口径或业务交互重构

## 方案对比

### 方案 1: 壳层替换，内容尽量不动

直接替换全局框架和视觉层，业务页面内部尽量保留。

- 优点: 风险最低，见效最快，容易保持现有功能稳定
- 缺点: 个别页面内部布局仍会保留旧痕迹，需要后续逐页微调

### 方案 2: 深度逐页迁移

逐页按参考项目重做结构和排版。

- 优点: 最终一致度最高
- 缺点: 改动范围过大，回归风险高，不适合本轮先做

### 方案 3: 只做视觉皮肤覆盖

保留旧布局，仅通过 CSS 模拟参考项目。

- 优点: 改得最快
- 缺点: 导航方式和页面节奏不会真正像参考项目

### 结论

采用方案 1。先完成壳层替换和通用视觉收口，再决定是否逐页深化。

## 设计

### 1. 全局布局骨架

当前项目外层结构是 `Sidebar + Header + main + footer`。本轮改为：

- `TopNav`
- `main`
- `footer`

布局规则：

- 页面整体背景改为参考项目使用的浅灰系背景
- 主内容区域采用更宽的居中画布
- 欢迎页保留更宽容器，业务页统一到较大但稳定的最大宽度
- 左侧边栏退出主导航职责，不再渲染为页面主体结构

### 2. 顶部横向导航

新增顶部导航作为一级信息架构承载层，负责：

- 系统品牌展示
- 一级页面入口
- 当前页面高亮
- 用户入口与通知入口
- 窄屏下的折叠展示

交互要求：

- 保持现有 `activePage` 切换模型
- 不改变权限判断逻辑
- 受限页面仍沿用原有鉴权逻辑，只是换到新的导航容器中展示

### 3. 视觉系统

视觉方向直接对齐参考项目，而不是延续当前项目偏现代后台的质感。

核心规则：

- 主色: 中石油风格深红
- 背景: 白色内容面板 + 浅灰页面底
- 表格头: 浅蓝底、深色文字、清晰边框
- 卡片: 较轻阴影、较平直的边界表达
- 字重: 页面标题和模块标题更强调业务平台感
- 控件: 筛选器、分页、链接操作更接近传统生产系统风格

### 4. 通用组件壳层

优先统一下列通用视觉对象：

- 页面标题栏
- 工具栏
- 卡片面板
- 表格容器
- 表头与表格边框
- 筛选标签与下拉框
- 主按钮、次按钮、危险按钮
- 分页样式
- 空状态与提示块

实现原则：

- 先通过 `src/index.css` 的主题变量和通用类收口
- 在 `src/App.tsx` 中替换主要壳层 JSX 容器类名
- 尽量少改业务数据结构，优先改容器和通用样式

### 5. 登录页、欢迎页、首页外层

这三块优先改造，因为最影响整体风格感知。

登录页：

- 采用参考项目更强品牌化的红白视觉
- 调整信息层级、背景、按钮和输入区间距
- 保留现有登录逻辑和离线兜底逻辑

欢迎页：

- 对齐参考项目的展示节奏和品牌感
- 让欢迎内容与全站顶部导航和整体配色形成统一

首页外层：

- 统一为参考项目的主舞台风格
- 优先调整统计卡、外层区块、工具条与内容节奏
- 首页内部的具体业务模块先不完全重做

## 风险与应对

### 风险 1: `src/App.tsx` 体量过大

当前文件体量很大，导航、页面、弹层和状态都耦合在一起。

应对：

- 只针对壳层结构和通用容器做局部替换
- 不重写业务数据流
- 不在本轮做大规模拆分

### 风险 2: 直接照搬参考项目会带偏现有功能

两个项目虽然相近，但当前项目已有更多数据接口和全局功能。

应对：

- 只抽视觉规则和布局方法
- 不整段复制参考项目业务组件

### 风险 3: 全局层级冲突

欢迎页、浮窗、登录弹层、通知和权限页都挂在全局骨架上。

应对：

- 重点检查固定定位、遮罩层级、导航层级
- 保留现有弹层状态逻辑，只修其容器样式和挂载位置
