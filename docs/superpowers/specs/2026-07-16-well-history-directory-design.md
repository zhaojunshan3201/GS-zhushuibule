# 井史目录二级菜单设计

## 目标

将“井史目录”由井号平铺列表改为“作业区 → 井号”的可折叠二级菜单，便于按作业区浏览井史。

## 范围

- 使用现有井史目录项的 `unit` 字段分组。
- 每个作业区显示名称和井数；所有分组初始均为展开状态。
- 点击作业区标题可折叠或展开其井号列表。
- 点击井号继续打开对应井史；删除按钮继续删除对应井史并刷新目录。
- 缺少作业区的井史归入“未分配作业区”。

## 交互与数据流

目录加载完成后，前端在渲染前将 `archives` 按 `unit` 分组。分组状态仅保存在当前页面的组件状态中，不新增接口或数据库字段。刷新目录后，现有分组的展开/折叠状态保留；新出现的作业区默认展开。

## 错误与边界

- 空目录仍显示“暂无井史目录”。
- 分组标题不触发井史打开或删除操作。
- 井号选中态、删除中状态与当前平铺列表保持一致。

## 测试

- 添加测试验证目录渲染按 `unit` 分组。
- 添加测试验证分组默认展开并支持切换折叠状态。
- 保留现有井号打开、删除及空目录行为测试。
