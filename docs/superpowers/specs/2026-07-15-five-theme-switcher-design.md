# 五套主题切换设计

## 目标

在不改变任何页面布局、导航层级、表格结构、数据字段或业务行为的前提下，为注水管理平台提供五套可切换的全局视觉主题。

## 主题

1. **专业油田蓝**：深蓝侧栏、雾灰工作区、蓝灰表头和橙色强调。
2. **极简企业白**：白色侧栏、钴蓝选中条、暖白页面和弱化表格网格。
3. **深色工业台**：石墨黑蓝工作区、冷青数据文本和琥珀重点操作。
4. **墨绿鎏金**：墨绿侧栏、米白工作区、薄荷表头和金色强调。
5. **当前默认主题**：保留当前实现的全部视觉 token，作为默认回退主题。

## 交互

- 仅在主页显示主题切换入口，使用紧凑的可访问下拉控件。
- 选择后立即将主题应用于整个应用壳层、按钮、表格、对话框和共享控件。
- 将主题键保存到浏览器 `localStorage`；重新打开系统后恢复上次选择。
- 缺失、损坏或未知存储值时回退到当前默认主题。
- 不改变任何现有页面的 DOM 结构、路由/菜单、数据请求、登录权限、写操作保护、导入导出或编辑交互。

## 实现边界

- 在 `src/App.tsx` 中维护主题状态、读取和保存逻辑，并在主页提供选择控件。
- 在 `src/index.css` 中为根应用节点定义主题数据属性选择器；每套主题仅覆盖颜色、阴影、边框和圆角等视觉变量。
- 新增最小回归测试，覆盖主题键校验、存储恢复和主题属性输出。

## 验收标准

1. 主页可以切换全部五套主题。
2. 主题切换立即生效且不改变当前页面、表格内容或操作功能。
3. 刷新后保留有效主题选择；无效值回退默认主题。
4. `npm test`、`npm run lint` 与 `npm run build` 通过。
