# 储量分析看板色系调整设计

## 目标

调整首页储量分析看板的指标色系，使上年度产油、动用储量、可采储量和总体贡献具有明确且一致的视觉语义，同时不改变布局、数据逻辑或交互行为。

## 色彩映射

| 指标 | 色值 | 应用范围 |
| --- | --- | --- |
| 上年度产油 | `#B91C1C` | 指标卡图标、组合图折线及图例 |
| 动用储量 | `#1D4ED8` | 指标卡图标、组合图柱形、排名图柱形及图例 |
| 可采储量 | `#6D28D9` | 指标卡图标、组合图柱形及图例 |
| 总体贡献 | `#7F1D1D` | 采一、采二对比卡片底部进度条 |

标定采收率继续使用现有蓝灰色 `#486581`，不跟随上年度产油颜色变化。总体贡献的百分比徽标、标签文字和数值保持现有样式，仅修改底部进度条。

## 实现方式

沿用 `HomeReserveAnalysisDashboard` 中集中维护颜色常量的现有结构，分别为动用储量、可采储量、上年度产油、采收率和总体贡献定义语义化颜色。图表与指标卡继续引用同一组常量，避免同一指标在不同区域出现色差。

不新增全局主题变量，不修改后端、数据派生逻辑、图表结构、排版或其他页面。

## 验证

1. 更新组件颜色契约测试，断言五个语义色值存在。
2. 运行储量分析看板相关测试，确认图表结构和无障碍属性未受影响。
3. 检查总体贡献暗红色只用于底部进度条，徽标与文字保持原样。

## 验收标准

1. 上年度产油显示为深红色 `#B91C1C`。
2. 动用储量显示为深蓝色 `#1D4ED8`。
3. 可采储量显示为深紫色 `#6D28D9`。
4. 总体贡献底部进度条显示为暗红色 `#7F1D1D`，其他总体贡献元素不变。
5. 标定采收率保持蓝灰色 `#486581`。
6. 相关自动化测试通过。
