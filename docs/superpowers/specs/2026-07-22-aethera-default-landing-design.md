# Aethera 默认首页设计

## 目标

将 `aethera-landing` 工作树中的 Aethera 落地页并入主分支，使系统访问根路径 `/` 时首先显示该动态首页。

## 路由与用户流程

- `/`：显示 Aethera 落地页。
- `/aethera`：继续显示同一落地页，保留直接访问地址。
- `/?page=home`：显示既有注水管理业务系统首页。
- Aethera 页的“进入注水管理系统”链接跳转至 `/?page=home`。
- 落地页的业务导航链接保持使用现有 `?page=` 参数，进入各对应业务页面。

## 实现范围

- 从工作树迁移 Aethera 页面组件、路径判断工具、所需样式/字体引用及 `oilfield-river.png` 图片资源。
- 主分支入口根据当前路径选择渲染 Aethera 页面或既有 `App`。
- 不迁移工作树中与本需求无关的 Axon、Duolingo 页面或其他未提交改动。

## 验证

- 路径判断测试覆盖 `/`、`/aethera` 与业务系统路径。
- 执行现有测试、类型检查和生产构建。
- 在浏览器验证 `/` 展示 Aethera，且“进入注水管理系统”可进入 `/?page=home`。
