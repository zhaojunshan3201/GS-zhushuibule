# 储量组合图 X 轴标签修正设计

## 目标

将首页“区块储量与产油表现”组合图中倾斜的六个区块名称改为水平正向显示，使中文标签阅读自然、字体一致。

## 修改范围

- 仅调整组合图 `XAxis` 的标签方向、文字样式和底部留白。
- 标签旋转角度设为 `0°`，文字锚点恢复居中。
- 使用页面现有中文字体与轴标签颜色，保持当前字号层级。
- 为最长区块名称预留足够宽度和底部空间，避免标签重叠或贴近坐标轴。
- 不修改数据、图例、柱线颜色、双轴、Tooltip、排名图、单位对比或下方表格。

## 验收标准

1. 雷11、雷04、雷72、牛心坨油层、牛心坨潜山、坨33 均水平显示。
2. 六个标签互不重叠，最长名称完整可读。
3. 桌面视图视觉居中；窄屏仍可通过现有横向滚动查看完整图表。
4. 自动化测试、TypeScript 检查和生产构建通过。
